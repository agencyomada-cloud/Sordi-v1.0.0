# Sordi

Système de gestion financière et commerciale pour **Omada Invoicing**.

## Fonctionnalités

- Gestion des Clients
- Facturation et Devis
- Bons de Commande et Bons de Livraison
- Suivi de Caisse et Paiements
- Génération de PDF (Factures, Bon, etc.)
- Statistiques et Rapports

## Technologies

- React / TypeScript
- Vite
- Tailwind CSS
- Shadcn UI
- Tauri (Desktop App)
